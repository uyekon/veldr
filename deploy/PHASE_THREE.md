# 阶段三：iOS / Android 本地版

## 交付范围

本阶段新增 `mobile/` Flutter 应用，目标是让用户在未登录、无网络的情况下完整记录和整理内容。它不复用浏览器 IndexedDB，也不会访问现有 CMS API；Web 数据流和生产部署保持不变。

本地模型采用 UUIDv7、整数版本号和软删除字段，与阶段二同步模型保持可映射。SQLite 包含 Notebook、父子分类、分类与 Notebook 多对多关系、文章、标签、文章标签、白板和附件元数据。文章及白板写入执行乐观版本检查，旧编辑会话不能静默覆盖新内容。

## 已实现功能

- 五栏移动导航：笔记、日记、白板、资料库、设置。
- 笔记全页编辑与 Markdown 阅读，支持标题、Notebook、分类、标签、置顶、归档、搜索和软删除。
- 图片复制到应用私有附件目录，正文使用 `attachment:` URI 引用。
- 日记 700ms 防抖、串行自动保存；转文章在单个 SQLite 事务中创建文章并清空日记。
- Notebook 与父子分类创建，分类可绑定指定 Notebook 或全局可见。
- 标准白板 ID：日记 `n`、临时 `t`、工作 `w`、每日推进 `dp`、灵感 `ideas`。
- 普通白板采用可新增、删除和长按排序的 Markdown 卡片；卡片以带版本前缀的 JSON 封装在原有单字段中，保留后续同步映射空间。
- 完整 ZIP 备份/恢复，包含 SQLite 逻辑快照与附件；支持多篇 Markdown 导入及 ZIP 导出。
- 暖灰与森林绿的移动端视觉系统，44px 以上主要触控目标，底部五栏导航。

## 自动化验收

```bash
cd mobile
flutter pub get
flutter analyze
flutter test
```

测试覆盖数据库初始化、标准白板、标签与置顶排序、归档默认隐藏、附件在文章更新后保持关联、分类清除、日记过期版本拒绝、日记原子转换、完整快照恢复，以及五个主导航入口。

## 上机验收清单

Linux 环境只能执行 Dart/Flutter 静态检查和 SQLite 测试。进入 TestFlight 前，需要在 macOS 与真机完成：

1. 中文输入法长文连续输入、光标移动、Markdown 工具栏和图片选择。
2. 强制退出、重启、飞行模式下确认内容与附件完整。
3. 日记自动保存过程中快速继续输入，确认最新内容不被旧结果覆盖。
4. 日记转文章后确认文章属性正确且日记仅在事务成功后清空。
5. 导出完整备份，新增内容，再恢复备份并核对文章、标签、分类、白板与图片。
6. iPhone SE 和常用大屏 iPhone 检查键盘遮挡、底部导航、安全区与动态字体。
7. Android 至少覆盖一台实体设备的返回手势、文件选择和后台恢复。

## 阶段边界

本阶段未接入登录、CMS API、跨设备同步、订阅或应用内购买。白板首版是结构化 Markdown 画布，不实现无限画布、自由拖拽和多人协作。正式签名构建、TestFlight 分发和商店材料属于后续阶段。
